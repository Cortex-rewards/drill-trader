DrillTrader - Fabric 1.21.11

Derleme (Java 21 + Gradle 9.x gerekir):
  1) Fabric template generator'dan (fabricmc.net/develop/template) bos 1.21.11 projesi indir
     ve gradle wrapper dosyalarini (gradlew, gradlew.bat, gradle/) bu klasore kopyala.
     (veya sisteminde Gradle kuruluysa: gradle build)
  2) ./gradlew build
  3) build/libs/drilltrader-1.0.0.jar dosyasini mods klasorune at (Fabric API de gerekli).

Kullanim: /drilltrader start   |   /drilltrader stop
